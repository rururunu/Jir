The problem

Multiple JDKs.
More complexity.

Different projects need different Java versions. Installing and switching between JDKs on Windows is a real hassle — and every switch means editing environment variables again.

Java 8

Zulu

C:\java\8

Java 17

Corretto

C:\java\17

Java 21

Temurin

C:\java\21 Active

How it works

One stable path.

jir keeps the active JDK behind a single home/occupy directory. Point JAVA_HOME there once — switching versions never touches your environment again.

Get started

Installation

Choose your preferred way to install jir — pick one channel, do not mix them. Each keeps its own directory and its own JDK library under home/.

Recommended

GUI installer

A graphical installer for Windows. It records the installation, so jir shows up in "Apps & features" and uninstalls normally, and it reuses an existing install directory.

Download installer
  • Choose the install directory
  • Can add jir to PATH and set JAVA_HOME
  • Ships uninstall.exe

Portable

PowerShell one-liner

No administrator rights: the script verifies the archive's SHA-256, extracts it, adds it to PATH and sets JIR_HOME.

iex (New-Object Net.WebClient).DownloadString('https://github.com/rururunu/Jir/releases/latest/download/install.ps1')
  • No uninstaller — remove its directory and the PATH / JIR_HOME entries yourself
  • Use this form rather than irm ... | iex: release assets are served as application/octet-stream, and a byte array piped into iex fails to parse
  • Already installed? jir update upgrades whichever copy you run

Command reference

Every command, at a glance.

A target is either a feature version (21) or a full version:distro pair (21:temurin). Give a version only, and jir asks which vendor you mean. Click any row to copy the command.

CommandWhat it does
jir, jir -h, jir --help, jir helpShow the help screen.
jir lsShow installed JDKs.
jir ls -iShow installable JDKs.
jir ls -i 21Show installable JDKs for one feature version.
jir i 21Install Java 21 and choose a vendor.
jir i 21:temurinInstall a specific distro.
jir i 21:temurin 17:correttoInstall several at once.
jir usePick from every installed JDK and activate it.
jir use 21Choose an installed Java 21 distro and activate it.
jir use 21:temurinActivate a specific installed distro.
jir currentShow the active Java runtime.
jir -vPrint the installed version.
jir uni 21Choose an installed Java 21 distro and remove it.
jir uni 21:temurinUninstall a JDK after confirmation (-y to skip).
jir updateUpdate jir itself to the newest release (--force to reinstall).

Small tool. Big convenience.
