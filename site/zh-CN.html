问题

多个 JDK，
更多麻烦。

不同的项目需要不同的 Java 版本。在 Windows 上安装、切换 JDK 本身就是件麻烦事——每次切换还得再改一遍环境变量。

Java 8

Zulu

C:\java\8

Java 17

Corretto

C:\java\17

Java 21

Temurin

C:\java\21 Active

工作原理

一个固定路径。

jir 把当前 JDK 收在唯一的 home/occupy 目录后面。只需把 JAVA_HOME 指向它一次——之后再切换版本，永远不用碰环境变量。

开始使用

安装

选择你偏好的安装方式——两条渠道选一个，不要混用。它们各自维护自己的安装目录和 home/ 下的 JDK 库。

推荐

图形化安装器

面向 Windows 的图形化安装器。它会记录安装信息，因此 jir 会出现在「应用和功能」里、可以正常卸载，并且会复用已有的安装目录。

下载安装包
  • 可以选择安装目录
  • 可以把 jir 加到 PATH、并设置 JAVA_HOME
  • 自带 uninstall.exe

便携

PowerShell 一行命令

不需要管理员权限：脚本会校验压缩包的 SHA-256，解压后把它加入 PATH，并设置 JIR_HOME。

iex (New-Object Net.WebClient).DownloadString('https://github.com/rururunu/Jir/releases/latest/download/install.ps1')
  • 不带卸载器——卸载需要自己删除目录并清理 PATH 与 JIR_HOME
  • 请用这种写法，不要用 irm ... | iex：Release 资产以 application/octet-stream 返回，字节数组直接管道给 iex 会解析失败
  • 已经装过？jir update 会就地更新你运行的那一份

命令参考

所有命令，一屏看完。

目标写法有两种：只写特性版本（21），或写完整的 version:distro（21:temurin）。只写版本时，jir 会询问你要用哪个发行商。点击任意一行即可复制命令。

命令作用
jir、jir -h、jir --help、jir help显示帮助。
jir ls查看已安装的 JDK。
jir ls -i查看可安装的 JDK。
jir ls -i 21只查看某个特性版本的可安装 JDK。
jir i 21安装 Java 21，并选择发行商。
jir i 21:temurin安装指定发行版。
jir i 21:temurin 17:corretto一次安装多个。
jir use从所有已安装的 JDK 中挑一个并激活。
jir use 21从已安装的 Java 21 中选择一个并激活。
jir use 21:temurin直接激活指定发行版。
jir current查看当前激活的 Java。
jir -v查看当前 jir 版本。
jir uni 21从已安装的 Java 21 中选择一个并卸载。
jir uni 21:temurin确认后卸载某个 JDK（-y 可跳过确认）。
jir update把 jir 自身更新到最新版（--force 可强制重装）。
